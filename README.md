# Logistics Analytics Project

## 1. Project Overview

This project analyses logistics operations using a 14-table dataset to identify performance patterns and generate business insights across key areas of logistics management.

The project focuses on understanding operational performance and supporting data-driven decision-making using SQL, Python, Power BI, and Excel.

## 2. Business Questions

The project investigates four key management questions:

- Are we delivering when we promised?
- Where is the operation spending too much?
- Are our people and equipment being used efficiently?
- What problems can we identify or predict before they become costly?

## 3. Management Themes

### Delivery Reliability 
Analyse delivery performance, delays, routes, facilities, scheduled versus actual delivery times, and detention.

### Cost Efficiency 
Analyse revenue, fuel costs, fuel efficiency, and maintenance costs to identify areas of operational cost.

### Asset & Resource Utilization
Analyse driver performance, truck utilization, trailer usage, workload, mileage, and fleet performance.

### Risk & Prediction
Analyse safety incidents, maintenance patterns, delivery delays, and operational factors to identify risks and investigate predictive modelling opportunities.

## 4. Tools & Technologies

- **SQL** — Data querying, filtering, aggregation, and business analysis
- **Python** — Data cleaning, descriptive analysis, predictive analysis, and machine learning
- **Power BI** — Interactive dashboards and data visualization
- **Excel** — What-If Analysis and Goal Seek

## 5. Dataset

This project uses a relational logistics dataset consisting of 14 interconnected tables representing different aspects of logistics operations.

The dataset is used to analyse deliveries, trips, fleet resources, drivers, costs, maintenance, safety, and other operational factors.
